# qcyqapps.github.io

Website of QcyqApps, the indie studio of Adrian Śliwka: https://qcyqapps.github.io

- `index.html`: home (games, Unity assets, about, contact)
- `support.html`: support for Unity assets and games
- `ground-telegraphs/`: Ground Telegraphs product page, with a playable WebGL demo in `demo/`

Plain static HTML and CSS, no build step.
